# Download Git 
***
- Go to homebrew site: **https://brew.sh**
- Open terminal
- Enter the command below: **/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"**
- There will be message at the end with command, run them:  ***Run these commands in your terminal to add Homebrew to your PATH:***
- in terminal write **brew help** to check if it worked or not.
- Enter **brew install git**
***
